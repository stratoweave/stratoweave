# Roadmap

## Next release: Fleet Manager

The next release will include [Fleet Manager](https://www.stratoweave.org/use-cases/fleet-management/), extending StratoWeave’s declarative approach to software lifecycle management across a fleet of devices. Operators will be able to select devices and a target release, plan upgrade campaigns around maintenance windows, and follow progress through a dedicated web interface. Controlled pacing and service-aware pre- and post-upgrade checks will help coordinate changes, while device adapters handle the platform-specific upgrade operations. Fleet Manager builds on the same models, transforms, and operational subscriptions used for service orchestration.
